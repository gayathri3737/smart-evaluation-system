# Smart Evaluation System

## Overview

The Smart Evaluation System is a web-based platform designed to automate and simplify the evaluation of student assessments. The system enables teachers to create tests, manage questions, evaluate responses, and monitor student performance efficiently.

This project aims to reduce manual effort in assessment processes while providing accurate and timely evaluation results.

---

## Features

### Student Module

* Student Registration and Login
* Access to Available Tests
* Online Test Participation
* View Scores and Performance
* Student Dashboard

### Teacher Module

* Teacher Registration and Login
* Create and Manage Tests
* Add, Edit, and Delete Questions
* View Student Submissions
* Monitor Student Performance

### Evaluation Module

* Automatic Evaluation of Objective Questions
* Score Generation
* Result Management
* Performance Analysis
